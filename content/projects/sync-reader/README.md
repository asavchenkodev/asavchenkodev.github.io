# Sync Reader

Sync Reader is a parallel text reader for learning German with Russian translations. It lets you read bilingual texts side by side, inspect words in context, save useful vocabulary, and export it for Anki.

[Open the live tool](/tools/sync-reader/index.html)

## Why I built it

The main idea is to see a word immediately in sentence context instead of only seeing a direct translation. You can also read the text first in your native language and then in the language you are learning.

The app stays serverless: no account, subscription, or paid usage limit. Texts, folders, saved words, and study data are stored locally in the browser.

## Features

- Parallel Russian and German reading panes.
- Linked highlighting across both texts.
- Saved vocabulary and Anki-style review.
- TSV export for Anki.
- A local library with folders and browser storage.
- Import for sentence-scoped JSON generated by an LLM.
